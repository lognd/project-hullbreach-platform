---
id: INV-006
statement: Bearer session tokens are never stored where page script can read
  them (localStorage, sessionStorage, non-HttpOnly cookies).
criticality: medium
evidence:
  - ticket 01M4GR6ES87DSS119XV7PR4BF7
---
Rationale: web/src/auth/session.ts persists the 14-day bearer token in
localStorage, so any XSS exfiltrates a long-lived credential.
