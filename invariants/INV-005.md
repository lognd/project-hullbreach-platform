---
id: INV-005
statement: No shipped default exposes the database to a non-loopback interface
  or authenticates with a well-known credential.
criticality: high
evidence:
  - ticket 01M4GR6EGFEXV770648K7YTHGG
---

Rationale: docker-compose.yml publishes 5432 on all interfaces with
POSTGRES_PASSWORD defaulting to "hullbreach" (user and db the same), and
AppConfig.database_url defaults to the same credential, so a developer machine
on a shared network is an open database and the default can leak into deploys.
