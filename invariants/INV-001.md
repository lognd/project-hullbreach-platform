---
id: INV-001
statement: The login path does equal password-hashing work and equal observable
  output for unknown and known usernames.
criticality: high
evidence:
  - ticket 01M4GR0CQQA02HKSTK8TDEV1SB
---
Rationale: login promises an identical 401 for unknown user and wrong password,
but api/auth.py short-circuits before verify_password when the user is absent,
so response time is an account-existence oracle. Any credential check must run
one Argon2 verify (against a dummy hash if need be) on every path.
Enforcement today is by ticket and review: this frob has no pattern-rule
engine, only `[invariants] forbid_imports`, so no POL rule can express it.
