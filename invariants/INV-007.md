Rationale: baseline guard from the repo-wide sweep. No such import exists in
src/hullbreach_server today; the rules flag any recurrence (command injection,
arbitrary-code deserialization).

The operator tooling (src/hullbreach_ops: doctor, start, stop) does spawn
processes, so it lives outside src/hullbreach_server and only the CLI entry
point (`__main__.py`) may import it. POL-ops-outside-server flags plain
`import hullbreach_ops`; tests/unit/test_ops_boundary.py also catches the
`from hullbreach_ops... import` form.
